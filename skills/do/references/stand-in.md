# The session in a fork's place

Read by the `ticket` Playbook's steps that fork `do-reader` or `do-builder`, only when the fork
cannot be made: the Agent tool is withheld from the session, or it lists no `do-reader` or no
`do-builder`, as it does on a machine that never linked the agent `do` ships. The reader's readers
are the door of [ticket.md](ticket.md), which forks `do-reader` for a Ticket with no Digest, and
every run that forks it again: a second run that finds a document moved, a Ruling that rewrote a
Ticket criterion, and the resume after `discuss` amended the Spec. The Builder's readers are the
build step of [ticket.md](ticket.md), which forks `do-builder`, and the Resume there, which forks it
at the first behaviour without a commit.
