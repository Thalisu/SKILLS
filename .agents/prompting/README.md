# prompting

Guidelines for using each model the right way: how to prompt it, which effort to run it at, and
the behaviors that differ from the model before it. One file per model, plus one for the practices
common to all of them, each a verbatim copy of the upstream page, so a refresh is a re-fetch and a
diff, never a rewrite. Quoted prompt text keeps its upstream punctuation.
