# skill-authoring

Guidelines for authoring a skill: how to keep a `SKILL.md` concise, how to write its `name` and
`description`, how to split it into reference files a model loads on demand, and how to ship
scripts with it. One file per upstream page, each a verbatim copy, so a refresh is a re-fetch and a
diff, never a rewrite. Quoted prompt text and code keep their upstream punctuation.
