# Changing a SKILL.md

Before changing a `SKILL.md`, read the case file that matches the change, then only the sections
it lists. The guideline files they point into are too long to read whole.

- Its body: `.agents/reading/skill-body.md`
- Its frontmatter or description: `.agents/reading/skill-frontmatter.md`
